01 // PROTOCOL ARCHITECTURE

            
Five phases. Zero delivered payloads.

          

          

            Every target domain flows through a deterministic async pipeline built on Tokio, Hickory DNS, and pure-Rust
            rustls. Select a stage to inspect the wire mechanics.
          

        


        

          

            
            
            
            
            
          


          

        


        

          

            
NET // 01TOKIO

            
Bounded Concurrency

            
Per-domain worker pool with configurable jittered delays (--delay-ms / --jitter-ms) and per-stage timeouts.

          

          

            
TLS // 02RUSTLS

            
Pure-Rust Crypto

            
Built on rustls-rustcrypto — compiles cleanly without OpenSSL or a C toolchain. Supports STARTTLS and port 465 implicit TLS.

          

          

            
MX // 03RFC 5321

            
Failover & Null-MX

            
Connect failures roll to backup MX hosts while real 550 answers stay authoritative. Handles RFC 7505 . null-MX records.

          

          

            
OPS // 04POLITE

            
Greylist & Anti-Block

            
Automatic 4xx retry rounds (--retry-greylist), randomized EHLOs, and plausible --auto-mail-from senders.

                Verdict
                Trigger Condition
                Operational Meaning
              

            
            
              

                accepted
                250 / 251 when catch-all is not confirmed
                Mailbox exists and accepts mail for this recipient
              

              

                accepted_catch_all
                250 / 251 on a confirmed catch-all domain
                Server accepted the candidate, but accepts random UUIDs too
              

              

                rejected
                550 5.1.1 / 5.1.2 / 5.1.10 or generic 5xx
                User unknown / mailbox unavailable at this host
              

              

                temporary
                4xx (421, 450, 451, 452)
                Greylisted or rate-limited — eligible for --retry-greylist
              

              

                policy_blocked
                5.7.x, MAIL FROM 5xx, or policy/RBL hints
                Sender-stage anti-enumeration or blocklist refusal (not mailbox state)
              

              

                indeterminate
                252
                Server refuses to verify user identity, but will accept message
              

              

                error
                TCP timeout, TLS handshake failure, EOF
                Transport-level failure after MX failover attempts
